# Roadmaps

## Generation State

- [Generation Index](generation-index.md) — live next-task pointer
- [g02](g02/README.md) — active; one executable task per `g02.NNN` file
- [g01](archive/g01.md) — complete; roll-up (expanded tree compacted)

## Completed Generation

g01 delivered the first generation of shared systems: 20 tasks and cards
001-137 covering configuration, backup/restore, display and windowing,
layout, optional Surface and transfer, Svelte/Poodle clients, settings,
bridge, commands/keymaps/palette, linear and optional fork-tree history,
operations/notifications, native-content islands, and five consumer
migrations (Nucleus, Loophole, Soundcheck, Split-shell, Jetstream). All g01
tasks are closed; the roll-up lives in
[archive/g01.md](archive/g01.md).

## Continuation

The [generation index](generation-index.md) owns the only live next-task
pointer. Consumer adoption does not auto-start Longhorn work.
