# g01 Shared Desktop Foundation And Adoption

Status: archived
Kind: roll-up

g02 succeeds this generation. This roll-up replaces the expanded `docs/roadmaps/g01/`
tree (generation README, 20 task files, 137 card records plus the batch-cards index), removed in the
flattened-task migration. Git history remains the full-fidelity archive; nothing
here is executable.

## Intent and boundary

Build the shared Rust and Svelte/TypeScript desktop systems once, prove them
against real consumers, and hold a private `0.1.0` compatibility candidate.
Boundary: generic Longhorn systems only. Product schemas, panel catalogues,
history payloads, and authorization stay in the consumer applications. Five
consumers migrated in-generation: Nucleus, Loophole, Soundcheck, Split-shell,
Jetstream.

## Shipped outcomes, by durable capability

- **Contracts and package topology (g01.001).** Working rules, vision-to-closeout
  delivery grammar, and the crate/package graph the generation built on.
- **Configuration, backup, restore (g01.002, g01.019).** Versioned domains, safe
  writes, backup, restore, encrypted envelopes, custom adapters, platform
  layouts, journaled profile transition, legacy discovery. g01.019 added grouped
  failure-atomic custom restore and boot recovery from the Nucleus g05.046 gap;
  Nucleus retains quiescence, database-open policy, and restart scheduling.
- **Display, coordinates, window host (g01.003, g01.004).** Pure display and
  geometry planning plus the native Tauri window apply/lifecycle host, proved
  with a packaged macOS arm64 restore/reveal/capture/restart matrix.
- **Layout core (g01.005).** Surface-independent layout state: identity, policy,
  atomic expected-revision mutation, registered persistence, generated
  TypeScript protocol, two-shape conformance.
- **Optional surfaces, transfer (g01.006).** Optional full hosting, bounded
  sessions and leased targets, same-document panel move, whole-surface
  transfer, packaged multi-window proof. Cross-document panel transactions,
  copy, and reusable UI adapters stayed explicit later work.
- **Clients, Svelte, Poodle, shell (g01.007).** Checked clients, thin UI
  adapters, domain-free transport, per-window Svelte state, Poodle public seam
  and preview artifact, three artifact-installed shell shapes.
- **Settings (g01.008).** Centralized composable registry, config-backed apply
  units, generated protocol, Tauri host, Svelte session, composition proof.
- **Bridge and topology (g01.009).** Pure negotiation and authority substrate,
  typed operations, checked TypeScript generation, direct/serialized-loopback
  conformance, Tauri assembly, supervision, five-shape topology proof.
- **Commands, keymaps, palette (g01.010).** Sealed registry, bounded arguments,
  deterministic physical-chord resolution, config-backed overrides, generated
  clients and host protocol, artifact proof.
- **History (g01.011, g01.017).** Public linear slice plus the promoted private
  fork decision; optional production fork-tree layer after linear adoption.
  Loophole keeps payload meaning, snapshots, autosave, and recovery choice.
- **Operations and notifications (g01.012).** Separate operation and
  notification authorities: bounded lifecycle, receipts, retention, ledger,
  projections, artifact proof.
- **Native-content islands (g01.013, g01.018).** Split production graph
  promoted from private evidence: isolated artifacts, three-shape parity,
  packaged support, adoption gates.
- **Consumer migrations (g01.014, g01.015, g01.016).** Nucleus Surface-free
  cutover; Loophole full-stack adoption; Soundcheck, Split-shell, Jetstream,
  greenfield composition, and the deterministic private `0.1.0` candidate
  (Card 127 receipt).
- **Child-view navigation (g01.020).** Retained policy-admitted child-webview
  navigation control.

## Material migrations, compatibility limits, retained risks

- Card 127's private `0.1.0` receipt is superseded, not rewritten, by the g02.008
  candidate re-freeze once its Poodle precondition clears.
- Child-view and backing-surface proofs never met live native scale transition
  on a multi-monitor host; recorded as unmet, carried by the g02 candidate
  runway until a host or simulation authority exists.
- Windows/Linux child-view and non-macOS display/transfer evidence outstanding;
  needs platform hosts.
- Donor baselines pinned at migration time: `39f08c04`/`09e633ce` (007 shell
  runway), `4b9835ef` (015 Loophole artifacts).
