## Objective

Prove minimal, product-rich, and advanced settings compositions from produced
artifacts, audit optional boundaries, publish guidance, and close g01.008.

## Scope

- produced Rust and TypeScript settings/config artifacts
- exact supported Poodle artifact
- Bovine-shaped one-page staged preference shell
- Soundcheck-shaped product plus storage/backup/restore shell
- Loophole-shaped immediate, staged, policy-controlled, hardware, and
  consumer-owned keybinding pages
- Nucleus-shaped absence fixture for Surface and backend pages
- modal, window, and panel hosts
- authority load before guarded reveal
- package, protocol, capability, peer, transaction, recovery, and UI audits
- composition guide and milestone closeout

## Public Behavior

Bovine installs only the settings foundation it needs. Soundcheck composes
shared recovery modules beside product pages. Loophole resolves custom
renderers and specialist commands without moving product authority. Nucleus
proves that an absent server or Surface module creates no dead navigation.

All shapes use checked authority, visible failures, public Poodle APIs, and
exact settings receipts. None uses sibling source aliases or a shared
application frame.

## Out Of Scope

- donor repository writes or cutover
- generic keybinding semantics
- backend connection implementation
- public npm or Cargo release
- Windows/Linux packaged runtime claims unless already available

## Steps

1. Pack every g01.008 Rust and TypeScript artifact.
2. Install isolated Bovine, Soundcheck, and Loophole proof consumers.
3. Install the exact supported Poodle artifacts without source aliases.
4. Mount minimal, product-rich, and advanced registry/shell shapes.
5. Exercise modal, window, and panel hosting.
6. Exercise immediate, staged, reset, policy, conflict, activation, storage,
   backup, restore, rollback, and recovery behavior.
7. Verify the Nucleus optional-module absence matrix.
8. Audit dependencies, peer runtimes, capabilities, payloads, atomicity,
   authority, receipts, accessibility, and Poodle use.
9. Publish composition and migration guidance.
10. Record retained, changed, deferred, and platform-limited behavior.
11. Close Cards 042-048 and g01.008.

## Acceptance Criteria

- every proof consumes produced artifacts
- no proof resolves sibling source
- Bovine resolves no layout, Surface, command, backend, or recovery package it
  did not compose
- Soundcheck combines consumer pages and shared recovery modules
- Loophole custom pages retain consumer renderers and commands
- Nucleus has no dead Surface or backend pages
- all three shell host forms use one registry/session contract
- invalid, stale, policy-blocked, or unconfirmed operations publish nothing
- recovery-required blocks ordinary mutation
- transaction receipts never overstate cross-domain atomicity
- one Svelte runtime and exact Poodle artifacts resolve per install
- root settings import has no upward optional edge
- full Effigy QA passes

## Evidence Required

- artifact identities and clean-install report
- dependency and peer-runtime matrix
- mounted registry/session/host matrix
- mutation, policy, activation, backup, restore, and recovery matrix
- capability, payload, transaction, receipt, UI, and authority audits
- behavior delta and deferred-work table
- settings composition guide
- milestone closeout log
- full Effigy QA

## Stop Conditions

- proof needs a donor repository modification
- one app shape requires product authority in Longhorn
- Bovine resolves an unused optional system
- a package resolves sibling source or duplicate peer runtime
- a settings receipt overstates persistence, activation, or recovery
- public Poodle APIs cannot support the shell
