## Objective

Prove artifact-installed minimal and full app-shell compositions, publish
reusable shell guidance, audit package boundaries, and close g01.007.

## Scope

- produced Longhorn package artifacts
- exact Card 038 Poodle preview artifact
- minimal Split-shell-shaped shell
- Nucleus-shaped Surface-free workspace
- full Loophole-shaped Surface and cross-window workspace
- public theme and presentation bootstrap
- authoritative load and visible-on-ready sequence
- narrow capability manifest examples
- loading, unsupported, reconnecting, and error surfaces
- package, peer, authority, and behavior audits
- milestone docs and evidence closeout

## Public Behavior

The examples share primitives and guidance, not one application frame.
Split-shell remains a small split shell. Nucleus composes window, layout, regions,
and panels without Surfaces. Loophole composes the full
display-window-Surface-container-region-panel hierarchy and cross-window drag.

Each example loads authority before reveal, applies public Poodle theme and
presentation setup, declares only needed capabilities, and renders failures
instead of silently falling back.

## Out Of Scope

- donor repository migration
- public npm or Cargo release
- production design parity
- settings, commands, history, or backend topology
- Windows or Linux packaged runtime claims

## Steps

1. Pack Longhorn artifacts and install them outside workspace resolution.
2. Install the exact Poodle preview artifact without source aliases.
3. Build the minimal Split-shell-shaped composition.
4. Build the Surface-free Nucleus-shaped composition.
5. Build the full Loophole-shaped composition.
6. Add theme, presentation, readiness, capability, and error guidance.
7. Exercise mount, reload, reconnect, destroy, and transfer behavior.
8. Audit dependency, peer, payload, UI authority, and package contents.
9. Record retained, changed, deferred, and platform-limited behavior.
10. Close Cards 036-041 and g01.007.

## Acceptance Criteria

- all examples consume produced artifacts
- no example uses sibling source aliases
- Split-shell imports no layout host unless its composition needs it
- Nucleus imports no Surface package
- Loophole shape resolves the full optional hierarchy
- minimal and full examples are materially different compositions
- theme and presentation use public Poodle APIs
- visible-on-ready follows authoritative initial load
- missing capability and host errors are visible
- Poodle remains visual authority
- package graph contains no upward optional edge or duplicate peer runtime

## Evidence Required

- artifact identities and clean install report
- three-shape dependency matrix
- theme, readiness, capability, and error-state guide
- mounted lifecycle and transfer report
- payload and authority audits
- behavior delta and deferred-work table
- milestone closeout log
- full Effigy QA

## Stop Conditions

- proof resolves sibling source instead of packed artifacts
- Poodle preview is not installable
- Surface code enters the Nucleus graph
- one mandatory shell frame is required
- consumer product policy must move into Longhorn
- proof would require modifying a donor repository

## Result

Three isolated consumers now install produced Longhorn tarballs and exact
Poodle Card 038 artifacts. Split-shell uses core and generic Svelte lifetime only.
Nucleus adds registered layout and Poodle bindings without any Surface
package. Loophole installs the full optional Surface and transfer graph and
mounts the display-window-Surface-container-region-panel hierarchy.

Each shell uses public Poodle theme and presentation APIs, loads checked
authority before guarded reveal, and renders loading, unsupported,
reconnecting, and failed states. Narrow capability examples differ by shape.
Mounted tests cover initial load, reveal order, missing capabilities, host
failure, connection teardown, session arming, authoritative transfer abort,
and cancellation on destruction.

The artifact verifier rejects source aliases, changed Poodle membership,
unexpected optional packages, duplicate Svelte runtimes, and broad capability
graphs. Composition guidance keeps Poodle as visual authority and leaves app
frames and product policy with consumers.
