## Objective

Prove the complete public linear history slice through isolated rich and
minimal artifact installs, publish lossless composition guidance, and pause
before private fork work.

## Scope

- produced Rust and TypeScript artifacts
- rich Loophole-shaped typed policy, transaction, persistence, journal,
  Tauri, Svelte, and Poodle composition
- minimal non-editor pure Rust and framework-neutral TypeScript composition
- record, coalesce, group, limit, undo, redo, checkout, reload, and recovery
  traces
- stale, apply, rollback, codec, durability, event-gap, and teardown failures
- dependency, capability, payload, authority, peer, and artifact audits
- linear composition and later Loophole migration guide

## Public Behavior

Both shapes use the same produced `longhorn-history` artifact. The rich shape
adds every optional edge explicitly. The minimal shape resolves none of them.

The Loophole-shaped proof preserves claimed successful behavior and improves
failure invariance and authoritative future projection. It is conformance
evidence, not a donor cutover.

## Out Of Scope

- Loophole repository writes
- branch prototype
- public registry publication
- project version or collaboration behavior

## Steps

1. Pack the history Rust and TypeScript artifacts.
2. Install isolated rich and minimal proof roots.
3. Exercise equal semantic traces across pure and renderer clients.
4. Drive a disposable Loophole-shaped journal from committed transitions.
5. Prove exact failure invariance and durability truth.
6. Audit minimal optional-edge absence.
7. Audit rich capabilities, payloads, peers, and Poodle APIs.
8. Publish composition, persistence, recovery, and migration guidance.
9. Record retained, improved, rejected, and deferred donor behavior.
10. Run full Effigy QA for the linear checkpoint.

## Acceptance Criteria

- proofs consume produced artifacts without sibling-source resolution
- minimal graph contains no Tauri, bridge, config, journal, Svelte, or Poodle
- rich graph keeps payload and model apply in consumer code
- successful Loophole-shaped record/navigation semantics remain equal
- apply and rollback failures preserve exact model and history
- persisted reload and journal suffix preserve cross-session undo
- renderer receives authoritative future entries
- no branch, project-version, or event-source claim enters public artifacts
- composition guidance distinguishes proof from g01.015 cutover
- full Effigy QA passes

## Evidence Required

- artifact identity and isolated install report
- rich/minimal dependency matrix
- semantic and recovery traces
- failure-invariance and durability matrix
- capability, payload, authority, peer, and Poodle audits
- composition and migration guide
- checkpoint log and full QA

## Stop Conditions

- a proof resolves sibling source
- the rich adapter cannot express one claimed live Loophole behavior
- minimal imports an optional edge
- journal replay needs hidden product policy in Longhorn
- full QA exposes a contract or boundary failure
