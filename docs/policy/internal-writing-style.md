# Internal Writing Style

Status: active  
Audience: agents and operators

## Rule

Use glue-light writing for internal work and normal thread replies:

- short
- blunt
- high signal
- minimal glue words
- no ceremonial phrasing
- no long prose when bullets work

Compression removes glue, not meaning. Avoid caveman theatre.

## Closeout

When useful:

1. what changed
2. current state
3. validation only when failed or confidence-changing
4. next move

Public docs and teaching material may use fuller prose.
