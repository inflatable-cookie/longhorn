## What This Thread Was Doing

published 0.4.1. This lane is Longhorn's tier: npm exact `0.4.1`, Rust git

## Why It Matters

pins `0.3.0` everywhere. The adapter's exact peer is the coordination point
for the later consumer wave; until this pin moves, every Longhorn proof
installs a release behind the published head.
