## Selected Boundaries

### Soundcheck

- stable product root `Soundcheck` under `shared-product-root-v1`
- canonical id `com.inflatablecookie.soundcheck`
- separate config and window domains
- modal settings/recovery composition
- scan structural operation authority
- isolated-window coordination around the disposable inspection helper
- retained soundcheck-library SQLite/scan authority and Signal plugin authority

### Bovine

- canonical-id `native-platform-v1` roots
- one versioned config domain and minimal settings shell
- exact private Poodle artifacts instead of unpacked aliases
- no layout, Surface, service, command, history, operation, notification, or
  native-content dependency

The current two-pane SplitView is not enough reason to create a registered
layout document. Repository, content, navigation, editorial, validation, and
Git meaning remain Bovine authority.

### Jetstream

- checked bridge snapshot ordering and resync
- shared command registry and keyboard resolution with injected product execution
- backing-surface coordination and Svelte viewport lifetime
- retained editor command meaning, renderer, WGPU, native view storage, frame
  loop, world, camera, picking, gizmo, and semantic-input authority
