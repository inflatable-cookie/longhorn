# Fork-tree Artifact Proof And Closeout

Date: 2026-08-03
Card: 074
Roadmap: g01.017

## Result

The optional fork-tree layer passes private produced-artifact proof. g01.017
is complete. No consumer branch mode or registry publication is authorized.

The Card 067 linear artifact proof remains the control. Its minimal graph
resolves no tree crate or package. New disposable consumers install document
and Loophole-shaped tree graphs without resolving Longhorn or Poodle sibling
source.

## Semantic And Failure Evidence

Rust produces exact-v1 payload-free renderer fixtures. Direct document and
Tauri-shaped Loophole clients reproduce the native summary, bounded path,
bounded branch, and atomic checkout trace. The Loophole controller tears down
its one listener exactly once.

The artifact crate reruns all 26 fork-tree tests: topology, divergent record,
mixed LCA navigation, stale/apply/rollback failure invariance, protected
pruning, checkpoints, persistence, migration, hostile input, and projections.
The proof additionally rejects stale record, truncated persistence, impossible
protected prune, and a 257-record page request without mutation.

## Boundary Audit

- `longhorn-history` has no tree dependency.
- Default tree startup loads one bounded linear path and no branch list.
- Rust and generated TypeScript enforce the same 256-record tree page ceiling.
- Product payloads, product apply, checkpoint content, storage, and recovery
  remain consumer authority.
- Poodle use stays on public controlled primitives.
- Project versions, merge, collaboration, and event sourcing remain absent.
- Loophole remains on its completed linear adoption; tree adoption requires a
  separate explicit lane.
