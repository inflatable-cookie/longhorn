## Decisions

- display ids are machine-local and correlation records confidence
- placement is outer origin plus inner content size; hit-testing uses outer
  bounds
- cross-window panel transfer is a new id-only transactional protocol
- Rust `serde` types generate checked-in TypeScript through `ts-rs`
- events use epoch and revision, with listener-before-snapshot handshake
- Svelte/Poodle adapters own lifetime and presentation binding, not durable
  truth
- no g01 umbrella package or empty optional-package placeholders
