`longhorn-support-log` keeps contract 025's whole-line-or-nothing promise when a write fails partway. A failed append now truncates the live file back to its pre-append length, so a later line can never join onto a partial JSON record; when that truncation fails too the log latches `repair_required` in `stats()` until the operator repairs the file. The short-write path is covered by unit tests with an injected writer (committed prefix then failure, failure before any byte, failed truncation, whole write). Pre-1.0 breaking: `LogStats` gains a `repair_required: bool` field (latched, defaults to `false`). Contract 025 is updated to match.
