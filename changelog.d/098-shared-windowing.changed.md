Tauri and GPUI now share ordered window apply, dependency skips, convergence readback, and lifecycle ports. Failed native-window admission discards the new window or tracks it for cleanup retry. GPUI closes flush pending captures, and shutdown receipts expose per-window failures. Tauri capture and event translation use the platform desktop mapper. Restore preserves the saved home through fallback, and the config sink serializes overlapping flushes. Use `execute_tauri_window_apply_in_place` in place of the removed Tauri dispatch and owning apply APIs. Import shared clocks, close handlers, capture records, and flush ports from `longhorn-windowing`. The Tauri lifecycle services and default capture constructors no longer take a mapper. Explicit capture and readback mapper constructors validate host support. Custom capture backends return `TauriWindowCaptureError`, and GPUI user-close handlers now take `&self`.
