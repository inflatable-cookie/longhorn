`GitWorkspaceState.root` is a `PathBuf`, the exact canonical root, not a `String`, so a non-UTF-8 root keeps its bytes; its serialized value is unchanged. `sync_workspace` and `switch_branch` now pass their `reload` closure a `&Path` instead of a `&str`. Migration: where a display string is needed, use `state.root.to_string_lossy()`; where a path is needed, use `&state.root`; change the reload closure from `|root| git.inspect_worktree(Path::new(root))` to `|root| git.inspect_worktree(root)`.
