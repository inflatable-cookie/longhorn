Settings search now folds case through the host on both routes. The Svelte route used a fixed en-US lowercase, so Turkish dotted and dotless i could disagree with Rust; it now uses the same host folding policy the Rust search already used. `@inflatable-cookie/longhorn`'s `searchSettingsRegistry` takes a third `services: SettingsSearchHostServices` argument, and `SettingsSession` requires `searchHostServices` in its options. This is a breaking change for Svelte consumers: each must pass a `foldCase` that follows its host's locale, and there is no default. Rust callers are unchanged.
