Git workspace credentials now stay scoped to the resolved HTTPS destination, and Git skips ambient credential helpers even when the app supplies no credential. Corrupt, unsupported and legacy plain-text grants require a new GitHub sign-in. Askpass credentials own their helper, and apps applying `env_vars()` to their own Git commands must clear configured helpers in their isolation block. Use `credential.is_some()` in place of the removed `credential_bridge_configured` helper.
