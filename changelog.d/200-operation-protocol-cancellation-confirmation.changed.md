`OperationCatalogue::execute_protocol_cancellation` now requires a `QueuedCancellationConfirmation` argument so consumer admission can pass `ConfirmedUnstarted` or `Unconfirmed` on the protocol path. Pass `QueuedCancellationConfirmation::Unconfirmed` to preserve prior behavior when consumer admission has not confirmed queued work never started, or `QueuedCancellationConfirmation::ConfirmedUnstarted` when it has.
