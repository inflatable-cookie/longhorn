Local private-output Rust routes (`proof:artifacts`, desktop-support conformance, native-content-local and both release-absence scans) now take their default scratch root from Oxide's registered removable build pool (`oxide pool describe --json`), not the unmounted `/Volumes/Builds/scratch`. `OXIDE_TASK_SCRATCH_ROOT` still wins, and a missing pool or root fails closed naming that variable. The internal-drive refusal is judged by volume rather than `TMPDIR`, so an external `TMPDIR` is accepted and a boot-volume `TMPDIR` is refused. The shell route `scripts/external-scratch.sh` now runs the same TypeScript rule. The release-absence scans read the rlib paths Cargo reports; `scripts/private-cargo.sh --build-dir` and the `buildDir` option of `privateCargoCommand` are removed.
