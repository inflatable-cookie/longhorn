**Breaking.** History, fork-history, notification, and operation session projections are read-only. Use session commands such as `setFilter`, `setPage`, `setPageSize`, and `select` to change session state. Copy projections before editing them locally. Replace `NotificationSession.controller` with session commands and lifecycle methods. Replace `NotificationSession.unobserve` with the unsubscribe function returned by `session.observe(observer)`.
