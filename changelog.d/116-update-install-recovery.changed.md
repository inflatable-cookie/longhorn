Native update installs stage per target and clean up only the current attempt’s files. Unix directory locks protect live workspaces from updates to ancestor bundles and serialize updates that share a parent, including privileged replacements. Platforms without these locks refuse native bundle replacement. Install targets inside the reserved workspace namespace are refused. If publishing and rollback both fail, the error reports both faults and the preserved bundle’s path. The next apply verifies the backup’s filesystem identity before restoring it. Unverified and legacy backups remain available for manual recovery.
