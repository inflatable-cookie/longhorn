Native update installs lock and stage per target and clean up only the current attempt’s files. Install targets inside the reserved workspace namespace are refused. An unwritable install directory is locked before invoking privileged replacement when there is no target workspace. If publishing and rollback both fail, the error reports both faults and the preserved bundle’s path. The next apply verifies the backup’s filesystem identity before restoring it. Unverified and legacy backups remain available for manual recovery.
