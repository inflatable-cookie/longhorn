Fixed `Git::worktree_identity` in `longhorn-git-workspace` to read the worktree root and Git common directory as exact bytes: a crate-internal runner drops only Git's single trailing record terminator (one `\n`) and builds the path with no trim and no lossy decode (`OsStr::from_bytes` on Unix), so sibling repositories such as `repository` and `repository ` (or a non-UTF-8 name and its lossy twin) no longer resolve to the same identity. The `HEAD` object ID (hex) and the `symbolic-ref` branch (refnames cannot contain spaces) keep their existing handling.
