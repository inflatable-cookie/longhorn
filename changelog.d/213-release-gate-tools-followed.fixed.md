`check:runner-tools` follows each release gate through the effigy task it runs and the shell scripts that task invokes, so a tool used inside `docs:rust`, `check:prototypes`, `release:floor` or `release:source-consumer` is checked against `release.yml`'s installs. Before, those gates reduced to `effigy` and their tools went unchecked. The shell reader handles heredocs, function definitions, arithmetic tests, `[[ ]]`, redirections and `exec` leases. A task form it cannot read, or a task that calls itself, now fails the check.
