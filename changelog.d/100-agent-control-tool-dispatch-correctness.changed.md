Agent-control `listen` tracks a per-document epoch across page reloads so events starting at seq 1 are never dropped, pushes selection updates over a `watch` channel, and bounds `wait_for` timeouts (`MAX_WAIT_TIMEOUT_MS = 300_000`) and individual `poll_until` checks. The stdio carrier disables HTTP proxies (`.no_proxy()`) and preserves `InstanceToken`'s `SecretString` posture. Discovery publication refuses to write tokens when `0o600` permissions cannot be enforced; `DiscoveryRecord::is_stale` and `HOST_SELECTION_ENTRY` are removed. Selection tombstones are bounded, expiry uses a single sweep path, cancelled/shutdown waits map to `ToolError::CancelledSelection`, and `set_file_input` validation errors map to `ToolError::InvalidArgument`. `RecordingDispatcher` now enforces deadlines during execution and result recording, frees active capacity via a drop guard if a dispatch future is dropped mid-callback, and removes the hard-coded-zero `DispatchMetrics::mutation_replays` field.
