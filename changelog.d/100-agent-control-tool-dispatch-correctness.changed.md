Agent-control `listen` tracks a per-document epoch across page reloads (recording full-document load as a `navigation` event at seq 1) so events starting at seq 1 are not dropped by a stale cursor within the bounded 64-event ring, pushes selection updates over a `watch` channel without resetting the 50 ms page-event poll interval (2 s per-eval bound), and bounds `wait_for` timeouts (`MAX_WAIT_TIMEOUT_MS = 300_000`, advertised in the MCP schema) and individual `poll_until` checks. The stdio carrier disables HTTP proxies (`.no_proxy()`) and preserves `InstanceToken`'s `SecretString` posture. Discovery publication refuses to write tokens when `0o600` permissions cannot be enforced; `DiscoveryRecord::is_stale` and `HOST_SELECTION_ENTRY` are removed. Selection tombstones are bounded (300 s / 256 entries), expiry uses a single shared-clock sweep path with atomic outcome delivery, cancelled/shutdown waits map to `ToolError::CancelledSelection`, and `set_file_input` validation streams without allocating decoded buffers, runs once on the MCP-to-Tauri path, and maps to `ToolError::InvalidArgument`. `RecordingDispatcher` now wakes idle callbacks at their deadline via a pure-`std` timer reactor, handles unrepresentable durations via `Instant::checked_add`, holds `max_outstanding_calls` occupancy until the callback future finishes or drops via `ActiveCallGuard`, and removes the hard-coded-zero `DispatchMetrics::mutation_replays` field.
