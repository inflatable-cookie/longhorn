Card 074 installs private produced artifacts into isolated document and
Loophole-shaped consumers. The existing linear-history artifact proof remains
the linear-only control.

The proof checks:

- no consumer resolves Longhorn sibling source
- document and Loophole-shaped Rust graphs stay explicit
- renderer traces match native payload-free projections
- the Loophole-shaped fixture retains 2,112 nodes and 65 branches
- dense persistence stays below the Card 072 bound
- path and branch reads return at most the requested 17 records
- Tauri, Svelte, and Poodle remain removable optional edges
