# Operation And Notification Artifact Proof

Four disposable consumers install produced artifacts into random temporary
roots. They never resolve Longhorn or Poodle sibling source.

- `minimal-operation`: pure operation authority and direct/serialized clients
- `soundcheck`: reconnectable scan lifecycle through direct and Tauri clients
- `loophole`: queued render, bridge/Tauri/direct parity, retained panel, toasts
- `notification-only`: retained domain records without operation or command

Private Rust source inventories compile offline. Rust-generated fixtures drive
the matching renderer clients; their public traces must be identical.
