# Native-content System Artifact Proof

Card 093 installs produced TypeScript archives and private Rust source
inventories into temporary isolated roots. It proves four Rust graphs, three
renderer protocol shapes, selected Svelte/Poodle composition, recorded macOS
mechanism evidence, exact target support, prototype disposition, and consumer
migration prerequisites.

Run through Effigy:

```sh
effigy proof:native-content-artifacts
```

No donor repository is written. Temporary roots are removed unless
`KEEP_NATIVE_CONTENT_ARTIFACT_PROOF=1` is set.
