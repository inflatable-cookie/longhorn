# Command System Artifact Proof

Card 061 installs two consumer shapes into clean temporary roots.

- `jetstream` imports only `@inflatable-cookie/longhorn-commands` and uses one global keyboard
  context.
- `loophole` adds Svelte, public Poodle bindings, and the settings protocol
  package over one shared catalogue and keymap.

The verifier also compiles and runs native Rust consumers from private crate
inventory archives. These are conformance proofs, not donor migrations. They
do not read or modify donor repositories.

Run:

```sh
effigy proof:command-system-artifacts
```
