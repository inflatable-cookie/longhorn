# @inflatable-cookie/longhorn-history

Checked metadata-only clients for the Longhorn linear history authority.

- root: protocol validation, injected ports, direct/serialized adapters, and
  listener-first controller
- `/tauri`: narrow invoke/event port over `@inflatable-cookie/longhorn-core` transport
- `/svelte`: per-instance reactive session
- `/poodle`: controlled linear history panel using public Poodle primitives

Product payloads, product authorization, apply transactions, persistence, and
recovery remain host-owned.
